Ouvrir la page d'essai

La partie complète, avec le duel et les quatre moments de la journée : sur la branche claude/ui-voile-9516af, lance npm run dev, puis ouvre ?play=1&new=1&name=Ren&v2=1. Pour aller droit à un moment : ?play=1&state=day1-morning (matin), day2-afternoon (midi), day2-dusk-won (fin de journée), day1-evening (nuit).
