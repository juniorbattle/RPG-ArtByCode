Essayer

La partie complète, avec le duel et les quatre moments de la journée : sur la branche claude/ui-voile-9516af, lance npm run dev, puis ouvre l'adresse nue pour commencer par le titre. Pour aller droit à un moment : ?play=1&state=day1-morning (matin), day2-afternoon (midi), day2-dusk-won (fin de journée), day1-evening (nuit), v2-forecourt-midday (une place). Duel seul : ?scene=arena&v2=1.

En jeu : Q ouvre la liste de ce qu'on peut faire ici, Esc le menu, E parle, les flèches parcourent les choix.
