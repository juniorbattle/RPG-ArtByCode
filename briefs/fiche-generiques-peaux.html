La couleur de peau des combattants génériques

Ta demande : « J’aimerai avoir de la diversite de couleur des personnages generiques generes en utilisant aseprite pour faire ces corrections ( exactement comme nous avons fait avec les pnjs ) car les personnages combattants ont tous la meme couleur de peau ». Fait comme pour les PNJ : leurs feuilles approuvées ne changent pas ; un masque de peau choisit les texels de peau sur chaque image, et ils prennent l’une des quatre peaux que tu as approuvées pour les PNJ (claire, moyenne, hâlée, foncée), au même rang de clarté. Pour chaque combattant, choisis une peau ; la recommandation donne une distribution variée. Les masques se relisent aussi dans Aseprite : un document par feuille, un calque par peau et un calque du masque (détail plus bas). Rien ne change dans le jeu avant ta relecture.

Une fois la fiche remplie

Dis-le dans la conversation. Je relis tes choix, je les consigne mot pour mot, j’inscris l’approbation et les empreintes dans le fichier des variantes, je refais les preuves (le duel et le visage de chacun sous sa peau, un défi joué, le jeu par défaut à 0 px contre main), puis je fusionne dans main.

Dans Aseprite : les documents de revue sont dans art-lab/characters/scratch/generic-skins/ du dossier du projet (un par feuille, <id>-x2-v1-peaux.aseprite et <id>-x3-combat-peaux.aseprite). Affiche un calque « peau : … » ou le « masque peau » (cyan), et parcours les images avec les étiquettes du duel. Une correction se note ici ; elle va dans le fichier des masques, jamais dans la feuille.
