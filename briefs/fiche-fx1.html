Les effets de combat façon RPGThreeJS

Le moteur de RPGThreeJS est porté dans le duel, depuis dev@5cc6119e, et les effets pixel que tu n'as pas validés sont retirés. Tout reste derrière un paramètre DEV : rien ne change dans le jeu tant que tu n'en décides pas. Les animations ci-dessous sont des pas figés ; le vrai jugement se fait en jeu, à la vitesse réelle.

Essayer en jeu

npm run dev, puis ?scene=arena&v2=1&fx=new. Ajoute &time=midday pour midi, &fighterdensity=combat pour Ren à ×3. Le mode jouable ne porte pas encore ce paramètre.

Coût

Au repos : rien. Au pire, les recettes les plus lourdes enchaînées : +1,0 ms la nuit, à égalité avec la nuit B ; +0,8 ms à midi, 1,1 ms sous elle. Démarrage inchangé, premier coup sans à-coup.

Jeu inchangé sans le paramètre

0 px contre main sur 47 vues, témoin à 0, contrôle négatif qui diffère. Paquet de production : 33 fichiers comparés.

Règles reprises

Un anneau de choc une seule fois, sur le coup. Une lame sombre sous chaque coupe. Le ralenti seulement au K.O., comme tu l'as choisi.
